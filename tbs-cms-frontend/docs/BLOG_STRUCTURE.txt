ROUTE MAP
=========

Public (No Authentication):
  GET  /tin-tuc                    → Blog listing with search & filters
  GET  /tin-tuc/[slug]             → Blog post detail page

Admin (Authentication Required):
  GET  /bai-viet                   → Admin blog list
  GET  /bai-viet/tao-moi           → Create new post
  GET  /bai-viet/[id]/chinh-sua    → Edit existing post

API ENDPOINTS (Backend Required)
================================

Public:
  GET    /api/blog-posts                    List posts (pagination, search, filters)
  GET    /api/blog-posts/slug/:slug         Get post by slug
  GET    /api/blog-posts/tags               Get all tags
  POST   /api/blog-posts/slug/:slug/view    Increment view count

Protected:
  GET    /api/blog-posts/:id                Get post by ID
  POST   /api/blog-posts                    Create post
  PATCH  /api/blog-posts/:id                Update post
  DELETE /api/blog-posts/:id                Delete post
