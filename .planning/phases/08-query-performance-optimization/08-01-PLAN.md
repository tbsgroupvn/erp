**Container findAll (container.repository.ts lines 39-61):**
Replace the `include` block in the `findMany` call within `findAll()` with a `select` projection. Keep `_count` for packages and orders. Select only the scalar fields needed for a list view:

```typescript
select: {
  id: true,
  code: true,
  status: true,
  shippingRoute: true,
  carrier: true,
  totalPackages: true,
  totalWeight: true,
  fillRate: true,
  maxCapacity: true,
  estimatedDepartureAt: true,
  estimatedArrivalAt: true,
  actualDepartureAt: true,
  actualArrivalAt: true,
  createdAt: true,
  updatedAt: true,
  _count: { select: { packages: true, orders: true } },
},
```

This replaces the existing `include: { _count: { select: { packages: true, orders: true } } }` which fetches ALL Container scalar columns. The `select` limits returned fields to only what the list table needs.

The return type of `findAll` currently is `Promise<{ data: Container[]; total: number }>`. Since `select` changes the inferred Prisma type, change it to `Promise<{ data: any[]; total: number }>` to avoid breaking TypeScript compilation. (The container service and controller pass this data through to the API response without strict type checking on individual fields.)

**IMPORTANT:** Do NOT change any other methods in these files (findById, findByCode, create, update, etc.). Only the list query methods get `select` projections. Detail endpoints keep `include`.

this.$on('query', (event: Prisma.QueryEvent) => {

    this.logger.error(
      `CRITICAL slow query (${event.duration}ms) | SQL: ${event.query} | Params: ${event.params}`,
    );

});
