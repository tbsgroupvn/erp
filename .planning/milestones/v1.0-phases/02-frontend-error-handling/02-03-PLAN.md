Remove per-hook duplicate toast.error calls from all 47 hook files to prevent double toast notifications.

Purpose: Plan 02-01 added centralized mutation error toast in QueryClient. TanStack Query v5 calls BOTH global and local onError. This plan removes the duplication while preserving hook-level toast.success calls and any non-toast logic in onError.
