3. **custom-throttler.guard.ts** -- Create new file at `src/common/guards/custom-throttler.guard.ts`:

- Extend `ThrottlerGuard` from `@nestjs/throttler`
- Override `getTracker(req)`: return `req.user?.id || req.ip` (userId for authenticated, IP for anonymous)
- Override `throwThrottlingException(context, throttlerLimitDetail)`:
  - Get response from `context.switchToHttp().getResponse()`
  - Calculate `retryAfter = Math.ceil(throttlerLimitDetail.ttl / 1000)`
  - Set `Retry-After` header on response
  - Throw `new DomainException(ErrorCode.RATE_LIMIT_EXCEEDED, 'Qua nhieu yeu cau. Vui long thu lai sau ${retryAfter} giay.', HttpStatus.TOO_MANY_REQUESTS)`
  - Use Vietnamese message with proper diacritics: `Qu\u00e1 nhi\u1ec1u y\u00eau c\u1ea7u. Vui l\u00f2ng th\u1eed l\u1ea1i sau ${retryAfter} gi\u00e2y.`
- Override `canActivate(context)`: check `context.getType()` -- if not 'http', return `true` (skip throttling for WS/RPC). Otherwise call `super.canActivate(context)`.
- Import: `ThrottlerGuard` from `@nestjs/throttler`, `Injectable, ExecutionContext, HttpStatus` from `@nestjs/common`, `DomainException` from `@common/exceptions/domain.exception`, `ErrorCode` from `@common/exceptions/error-codes`

4. **file-validation.pipe.ts** -- Create new file at `src/common/pipes/file-validation.pipe.ts`:

- Export `FileValidationOptions` interface with `maxSizeBytes: number` and `allowedMimeTypes: string[]`
- Export `FileValidationPipe` class implementing `PipeTransform`
- Constructor receives `FileValidationOptions`
- `transform(file: Express.Multer.File, metadata: ArgumentMetadata)`:
  - If `!file` return `file` (optional file uploads)
  - If `file.size > options.maxSizeBytes`: throw `new DomainException(ErrorCode.FILE_TOO_LARGE, 'File qu\u00e1 l\u1edbn. T\u1ed1i \u0111a ${maxMB}MB', HttpStatus.BAD_REQUEST)` where `maxMB = options.maxSizeBytes / (1024 * 1024)`
  - If `!options.allowedMimeTypes.includes(file.mimetype)`: throw `new DomainException(ErrorCode.FILE_TYPE_NOT_ALLOWED, 'Lo\u1ea1i file kh\u00f4ng \u0111\u01b0\u1ee3c ph\u00e9p: ${file.mimetype}', HttpStatus.BAD_REQUEST)`
  - Otherwise return `file`
- Import: `PipeTransform, Injectable, ArgumentMetadata, HttpStatus` from `@nestjs/common`, `DomainException` from `@common/exceptions/domain.exception`, `ErrorCode` from `@common/exceptions/error-codes`
