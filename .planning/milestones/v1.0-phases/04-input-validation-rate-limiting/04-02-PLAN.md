3. Fields to EXCLUDE from sanitization (do NOT add @SanitizeHtmlStrict):
   - IDs, codes, enum values (e.g., `orderId`, `status`, `type`, `priority`)

   - URLs (`@IsUrl()` fields)
   - Numeric fields (`@IsNumber()`)
   - Date fields (`@IsDate()`)
   - Boolean fields (`@IsBoolean()`)
   - Array fields containing non-string items
   - Password fields
   - File paths, storage keys

4. Decorator placement order (top to bottom on each property):
   ```typescript
   @SanitizeHtmlStrict()  // First: transform runs before validation
   @IsOptional()           // If applicable
   ```
