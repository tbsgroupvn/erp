### 🔴 C1: NPM Dependencies có lỗ hổng bảo mật

**Nguy hiểm:** Hacker có thể khai thác các lỗ hổng đã biết trong các thư viện

| Package | Severity | Ở đâu | Vấn đề |
|---------|----------|-------|--------|
| `axios` | 🔴 High | Frontend | SSRF vulnerability |
| `tar` (via `@mapbox/node-pre-gyp`) | 🔴 High | Backend | Path traversal |
| `@ducanh2912/next-pwa` | 🔴 High | Frontend | Qua `workbox-build` |

**Cách sửa:**
```bash
# Backend
cd tbs-erp-backend && npm audit fix

# Frontend  
cd tbs-erp-frontend && npm audit fix
```

---

### 🔴 C2: Thiếu Rate Limiting trên Auth Login

**Nguy hiểm:** Kẻ tấn công có thể brute-force mật khẩu liên tục

**File:** `auth.controller.ts` — endpoint `/auth/login`

**Cách sửa:** Thêm `@Throttle({ default: { limit: 5, ttl: 900000 } })` vào login endpoint
