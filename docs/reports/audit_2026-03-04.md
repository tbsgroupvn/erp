## ✅ Điểm Mạnh (Ghi Nhận)

Dự án TBS ERP Backend có nền tảng bảo mật **rất tốt**:

1. ✅ **Password hashing** — Dùng `bcrypt` với 12 rounds (`BCRYPT_ROUNDS = 12`) — đúng chuẩn
2. ✅ **JWT + Refresh Token rotation** — Token được hash bằng bcrypt, refresh token xoay vòng sau mỗi lần dùng để phát hiện token theft
3. ✅ **2FA hoàn chỉnh** — Hỗ trợ TOTP + SMS OTP + Backup codes, secret được mã hoá AES-256 (PBKDF2)
4. ✅ **CSRF Protection** — `CsrfGuard` được đăng ký global ở `APP_GUARD`
5. ✅ **Rate Limiting** — `ThrottlerModule` 100 req/min global; auth endpoints 5 req/15min
6. ✅ **Helmet** — Bảo vệ HTTP headers tự động
7. ✅ **Input Validation** — `ValidationPipe` với `whitelist: true, forbidNonWhitelisted: true` trên toàn bộ API
8. ✅ **Authorization Guards** — `JwtAuthGuard + RolesGuard` (và `DataScopeGuard`) có mặt trên hầu hết controllers
9. ✅ **N+1 Prevention (GraphQL)** — `DataLoaderService` với batching per-request cho customer, order, package, user
10. ✅ **Pagination** — Hầu hết `findMany` đều có `take: query.limit` hoặc hardcoded limit an toàn
11. ✅ **Secrets trong .env** — `.gitignore` bảo vệ `.env`, `.env.local`, `.env.production`; không phát hiện API key hardcoded trong source
12. ✅ **Sensitive data masking** — Audit log interceptor, Sentry filter, và Performance extension đều mask `password`, `token`, `secret` trước khi log

## 🟡 Warnings (Nên Sửa)

### ⚠️ W-01: `task.controller.ts` thiếu `RolesGuard`

**File:** `src/modules/task/task.controller.ts:27`  
**Tình trạng:** Controller chỉ dùng `@UseGuards(JwtAuthGuard)` — bất kỳ user đã đăng nhập nào đều truy cập được, không có phân quyền theo role.

**Giải thích đời thường:**  
> Tất cả nhân viên (kể cả bảo vệ, tài xế) đều có thể xem/tạo task của bộ phận khác.

**Cách sửa:**
```typescript
// task.controller.ts
@UseGuards(JwtAuthGuard, RolesGuard)
```
Và thêm `@Roles(...)` decorator lên các endpoints nhạy cảm.

### ⚠️ W-04: Hardcoded PBKDF2 salt trong `auth.service.ts`

**File:** `src/core/auth/auth.service.ts:103`  
```typescript
const salt = 'tbs-erp-2fa-encryption-salt'; // Hardcoded!
```
**Giải thích đời thường:**  
> "Muối" mã hoá 2FA bị hardcode trong source code. Nếu source code bị lộ, kẻ tấn công biết được salt này và có thể tăng tốc độ crack mật khẩu.

**Cách sửa:**  
Chuyển salt vào `.env`:
```typescript
const salt = this.configService.get<string>('TWO_FA_ENCRYPTION_SALT') 
  || 'tbs-erp-2fa-encryption-salt'; // fallback
```
```env
TWO_FA_ENCRYPTION_SALT=<random-32-bytes>
```
